# Motorcycle Simulation

النسخة التنفيذية الحالية لمحرك محاكاة مشروع تأجير الدراجات النارية المنتهي بالتمليك.

## Repository policy

يحتوي المستودع على الكود، الاختبارات، `state.json`، ولقطات النتائج المضغوطة اللازمة للاستئناف فقط. لا يُرفع المرجع الحاكم، ولا التقارير النهائية، ولا ملفات Excel.

## Stage 7 GitHub gates

يحتوي `.github/workflows/stage7-gates.yml` على أربع بوابات مستقلة:

1. نظافة المستودع والتحقق من عدم وجود المرجع أو التقارير أو ملفات Excel.
2. تشغيل مجموعة اختبارات القبول كاملة وعددها 163 اختباراً.
3. تشغيل 3 تكرارات من `C100_G100` بعاملين ثم 4 عوامل ومقارنة البصمات حرفياً.
4. إيقاف التنفيذ عند نقطة تحقق، حفظ الحالة، ثم استئنافها ومقارنة بصمة الحالة النهائية حرفياً.

## Important status

هذه الحزمة لا تبدأ محاكاة المشروع الرئيسية أو أي تشغيل مونت كارلو واسع. تشغيل بوابة التوازي محدود إلى 3 تكرارات مخصصة لإثبات حتمية التوازي المطلوبة في هذه المرحلة.

آخر تشغيل قبول محلي موثق في `state.json` هو 163 اختباراً: 119 ناجحاً و44 فاشلاً. لم تُخفَ هذه النتيجة في CI.
